# P3 경기 채팅·결과 화면 개선

## 요청과 적용
- 기존 게임판 주위 빈 공간에 두 플레이어의 **경기별 실시간 채팅** 추가.
- 데스크톱은 **왼쪽 채팅 / 중앙 게임판 / 오른쪽 턴 기록**의 고정 3열, 모바일은 게임판 → 채팅 → 기록 순서.
- 메시지는 `match_messages`에 저장, 두 플레이어만 RLS로 읽을 수 있습니다. 인증된 두 참가자만 전송 RPC 호출 가능하며, 280자·1초 제한·경기당 500개 상한을 둡니다. 같은 경기가 끝나도 30분까지 채팅 가능.
- 새 메시지의 Realtime INSERT 이벤트에서 Server Component 데이터를 갱신하며 기존 3.5초 폴링도 백업으로 유지.
- 게임 종료 시 게임판 중앙 결과 화면에 **내 관점의 승리/패배/무승부**, 랭크전은 **본인 `rating_history`의 delta 및 전/후 RP** 표시.
- 결과 바로 아래 **로비 복귀/재도전**: 일반전은 양측의 기존 재대전 투표(1/2 → 2/2), 랭크전은 새로운 랜덤 매칭 등록.
- 점수 계산·승패 확정은 기존 서버 DB RPC 그대로이며 UI에서 임의로 점수를 예측하지 않습니다.
