# P3 채팅 포커스·경기 결과 모션 개선 (2026-10-29)

## 실사용 피드백
- Enter 전송 후 채팅 입력 포커스가 풀려 매번 클릭해야 하는 불편함
- 승패/랭크 RP 결과 카드가 순간적으로 나타나 화면이 딱딱하게 느껴짐

## 변경
- 원인: 전송 중 `textarea disabled={sending||closed}`로 브라우저가 입력 포커스를 해제함.
- 전송 중 입력은 `readOnly={sending}`로 잠깐 막고, 채팅이 닫힌 경우에만 `disabled={closed}` 처리.
- Enter/Shift+Enter/한글 IME 및 기존 전송 버튼은 유지. 서버 RPC/DB 권한과 1초 채팅 간격은 변경하지 않음.
- 서버 응답 및 메시지 갱신 뒤, **입력창에서 전송을 시작했고 사용자가 다른 컨트롤로 이동하지 않은 경우에만** 포커스를 안전하게 복구. `preventScroll`로 게임 화면 스크롤 방지.
- 결과 배경은 180ms 페이드, 결과 카드는 260ms 페이드 + 9px 소폭 상승 + 0.985→1 배율로 표시.
- `prefers-reduced-motion: reduce` 설정 시 진입 애니메이션을 제거. 결과 위치·크기·승패/RP/재도전 버튼 구조 유지.

## 검증
- React 코드의 입력 비활성/readonly 및 포커스 복구 가드 회귀 테스트
- SSR 게임 결과창·CSS 키프레임과 동작 줄이기 검사
- CI / Vercel Preview / Production 확인
- 사용자 실측: Enter 연속 전송, Shift+Enter 줄바꿈, 한글 입력, 재전송·버튼 클릭 포커스 유지, 일반전·랭크전 종료 모션 확인

기존 P2 2차 제출 스냅샷과 DB·서버 물리·RP 정산 로직은 변경하지 않습니다.
