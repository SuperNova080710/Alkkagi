1. **운영 보안(#16/#62/#65):** Supabase Auth 최소 비밀번호 정책, 무료 플랜에서 불가한 leaked-password-protection 경고, SECURITY DEFINER RPC 권한 심층 점검, 실계정 권한 침투/부하 시험.
2. **UI 통합(#51/#86):** 최신 main 실제 계정/DB E2E 및 최신 Production 배포 상태 확인. 기존 P3·모의 UI QA와 구분.
3. **친구·DM(#72/#77):** SQL 004→005→006 운영 적용 여부, RLS/권한/Realtime, A/B 요청→수락→메시지→읽음→차단 검증. 메신저 **화면 자체는 아직 별도 구현 필요**.
4. **친구 초대(#82/#90):** PR 리뷰 후 승인된 경우만 병합. 마이그레이션 007 및 실제 서로 다른 사용자/코드 참가 동시경합 E2E 수행. 마이그레이션 없이 UI 활성화 금지.
5. **친구 관리 UI(#92/#96):** PR 리뷰·병합 전까지 기본 OFF. 운영 친구 DB 적용 후 설정 플래그 변경 여부 결정.
6. **AI(#47):** 쉬움/보통/어려움의 실제 브라우저 연습전 플레이 확인.
