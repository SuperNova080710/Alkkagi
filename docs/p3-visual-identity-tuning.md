# P3 사용자 피드백 — 보드 표시 간소화 (2026-10-28)

## 발견한 점
- 게임 안에서 내 알에 표시된 점은 유용하지만 **이중/점선 외곽선은 시각적으로 과함**.
- 각 진영 색상을 나타내는 **보드 내부의 불투명 라벨이 게임판 일부를 가림**.

## 적용 사항
- 게임판 위에 색상·진영 배지를 그리던 SVG 요소 제거: 보드 전체가 보임.
- 기존 게임판 상단의 두 선수 카드에 **'내 알 · 주황색/파란색 · 선공/후공'**, 닉네임·잔여 알·현재 턴 표시 유지.
- 실제 알에는 작은 **'나' 문자만 남기고 추가 바깥쪽 점선 링 제거**. 기본 외곽선은 2.5px에서 1.5px로 줄임.
- 해당 변경은 **일반전과 랭크전 공통 GameBoard**에 적용. 포인터/키보드 조작, 물리 엔진, 점수 정산, Supabase 스키마 변경 없음.
- 데스크톱 게임 화면 상단 높이는 기존 고정 4.5rem을 유지하고, 턴 변경 시 높이는 그대로 유지.
- CSS, 서버 상태, DB 스키마 변경 없이 UI 및 표현용 단위 테스트만 보완.

## 확인 방법
1. 일반전·랭크전에서 **왼쪽/오른쪽 보드 모서리의 겹치는 라벨이 사라졌는지** 확인.
2. 두 계정에서 **내 알은 주황색/파란색 중 어느 색인지**, 현재 턴·닉네임이 위쪽 카드에 구분되는지 확인.
3. 내 알에 '나' 글자는 남고, 추가 점선 테두리가 사라졌는지 확인.
4. 1366×768 등 데스크톱 게임 화면의 세로 스크롤·움찔거림, 모바일 터치 사용성 회귀 확인.
