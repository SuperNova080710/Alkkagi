# ALEPH P3 최종 제출 입력문 — Alkkagi Arena (2026-10-29)

> **준비 상태:** 폼 입력문·필수 발표 파일·선택 증빙 파일 준비 완료. ALEPH 사이트 **제출 접수/승인 미확인**. 이 문서는 P2 점검 스냅샷 이후 추가 구현한 내용에 초점을 맞춥니다.

## 이번에 만든 것 (`made`)

2차 점검에서 완성한 1:1 일반전·랜덤 랭크 매칭·Elo RP·리더보드에 이어, 동료들과 직접 게임을 플레이하며 발견한 사용성 문제를 개선했습니다. 경기 시작 시 본인의 알 색상과 선공·후공, 현재 턴, 닉네임을 상단 선수 카드에 명확히 표시하고, 게임판을 가리던 안내와 과한 알 테두리를 제거했습니다. 계정별 닉네임 설정 및 중복 확인 기능을 추가했으며, DB 고유 제약으로 대소문자만 다른 중복 닉네임과 동시 등록 충돌도 방지했습니다. 변경한 닉네임은 게임·턴 로그·리더보드에 반영됩니다.

빈 공간을 활용해 경기 참가자 두 명만 사용할 수 있는 실시간 채팅을 추가했습니다. Enter 전송, Shift+Enter 줄바꿈, 한글 입력 조합 보호, 전송 후 입력 포커스 유지까지 개선했습니다. 경기 종료 시에는 승리·패배·무승부와 랭크전 RP 증감 및 정산 전후 점수를 보여주고, 그 아래에 로비 복귀·재도전 버튼을 배치했습니다. 결과 화면에는 짧은 진입 애니메이션과 동작 줄이기 설정을 적용했습니다. 모든 변경은 배포되었고 GitHub Actions 검사가 성공했습니다.

## 확인하는 방법 · 3단계 이내 (`verify`)

1. https://alkkagi-alpha.vercel.app 에 서로 다른 두 계정으로 로그인한 뒤 로비의 닉네임 설정에서 닉네임을 변경하고 중복 확인 기능을 살펴봅니다.
2. 초대방 일반전 또는 랭크 아레나에서 매칭하여 내 알 색상·현재 턴·닉네임을 확인하고, 좌측 채팅에서 Enter 전송·Shift+Enter 줄바꿈·연속 입력을 사용하며 게임을 진행합니다.
3. 경기를 종료해 승패 결과와 랭크전 RP 증감·정산 전후 점수, 로비 복귀 및 재도전 버튼을 확인한 뒤 랭크 리더보드·전적을 대조합니다.

## 바뀐 점과 그 이유 (`changed`)

2차 점검까지는 두 사람이 정상적으로 경기를 진행하고 랭크 점수를 정산하는 데 집중했습니다. 이후 동료들과 플레이하면서 내 알과 차례가 한눈에 구분되지 않고, 게임판 내부 안내가 플레이 영역을 가리며, 채팅할 공간과 명확한 종료 결과가 부족하다는 점을 발견했습니다. 이를 해결하기 위해 상단 선수·턴 표시를 통합하고 게임판 장식을 줄였으며, 닉네임 설정·경기별 채팅·승패 및 RP 결과창·재도전 동선을 추가했습니다. 추가 테스트에서는 Enter 전송 후 채팅 입력 포커스가 풀리고 종료 화면이 딱딱하게 나타나는 불편을 확인하여, 포커스 유지 처리와 절제된 결과 애니메이션을 적용했습니다. 게임의 핵심 판정·랭크 정산 로직은 유지하면서 실제 사용성을 개선한 것이 이번 단계의 핵심 변화입니다.

## AI에게 맡긴 일과 내가 판단한 일 (`aiDecision`)

AI에게 Next.js 컴포넌트 수정, 닉네임 중복 방지 SQL·인증 RPC, 참가자 전용 채팅 테이블 및 RLS, Realtime 연동, 결과 UI·키보드 입력 처리·애니메이션, 자동화 테스트, GitHub PR과 Vercel 배포 작업을 맡겼습니다. 저는 1:1 알까기와 랭크 경쟁이라는 서비스 방향을 결정했고, 2차 이후에는 동료들과 실제로 플레이하면서 내 알·턴 식별, 게임판 가림, 닉네임, 채팅, 결과 표시, Enter 전송 포커스 등 사용자가 느끼는 불편을 발견해 개선 요구와 디자인 강도를 직접 판단했습니다. 수정된 게임을 다시 사용해 적절한 수준인지 확인했으며, 랭크 점수·리더보드 정상 작동도 확인했습니다. 코드 검사·운영 DB 수치는 AI의 도구 검증 결과로 별도 구분했습니다.
